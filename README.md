# transhumanism-redirect

Forwards **transhumanism.com.au** (and www) to **[transhuman.com.au](https://transhuman.com.au)**, keeping the path,
so old links like `transhumanism.com.au/peterxing` still land on the right page. GitHub Pages serves `index.html` for
the home page and `404.html` for every other path; both forward with JavaScript (and fall back to the home page).

The site itself lives in [peterxing/transhumanism-australia](https://github.com/peterxing/transhumanism-australia).
